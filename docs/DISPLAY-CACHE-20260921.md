# 9月21日展示与缓存修正

继续更新 agent/transition-runtime-20260919（PR #23），不另开平行修复分支。main 检查时仍缺少此前缓存/箭头修改；手机必须安装此分支编译的新包。

## 缓存口径

|范围|有效期|缓存内容|更新方式|
|---|---|---|---|
|首页四频道|5分钟|每频道列表、游标、hasMore；最多4频道×200条|频道切换复用，过期静默刷新，偏好变更清除，主动刷新重新请求|
|品牌目录|5分钟|品牌列表，含空结果；并发请求共用一次请求|列表服务复用，发现页返回不闪骨架|
|三榜|1分钟|各榜接口结果，最多3组|返回/切榜先显示缓存，过期重新拉取；右上角刷新立即拉取|

全部是当前 App 进程的内存缓存，进程被关闭后消失，不是磁盘离线缓存；没有后台定时轮询。榜单缓存内计数与顺序属于上次响应的快照，浏览/收藏变化不在页面本地伪加，主动刷新后以服务器结果为准。失败不覆盖已有结果。

## 展示调整

- 品牌目录固定首位：星辰猫 · 展示样例。完整简介、logo、坑向、关联原月光曲样例，独立ID，不写生产库，不替换真实品牌。各坑向筛选仍保留首位对照样例；删除“其他”筛选项。样例关注/屏蔽/收藏不会写服务端。
- 商品摘要品牌和标签同排；长品牌省略。默认“预约批/现货批”与状态重复时隐藏，独特批次名称仍显示。
- 两条对照商品增加仅用于展示的款式/尺码，不推断真实商品规格。旧说明只有“展示价格、发售、收藏、提醒和购买记录”的占位文字，隐藏；真实非空说明保留。
- 消费日志恢复预算在上、居中月份在下。左右图标使用 month-left/month-right SVG，镜像坐标、相同大小，不能再打包 main 的 arrow-back/arrow-right 组合。
- 收藏取消嵌套底色卡；个人选择显示“我·想买 ›”，日期显示“9月28日截定/10月8日尾款/9月25日开售”。缺日期不显示空行；无有效日期、已购买时不显示新增提醒操作。
