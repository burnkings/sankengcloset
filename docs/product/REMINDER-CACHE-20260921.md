# 提醒时间与读取缓存修正

## 用户可见变化
- 月份导航的通用右箭头去掉横线，并与左箭头镜像；消费日志已有专用镜像月份图标。
- 提醒日期、周几、时间合成一行，打开面板选择；取消恢复原值。全天为当天09:00通知。
- 来源含时间的尾款、日历及商品发售入口保留时间，按设备当地时间展示。商品发售采用开始时间，尾款采用截止时间；没有时间不伪造来源时间，使用表单默认值。
- 待提醒的过去时间显示行内提示并阻止保存。
- 保存结果使用确认弹窗，明确区分通知权限；用户确认才返回，不依赖导航期间Toast的存活时间。
- 固定格裙样例提供45cm参考价128元、55cm参考价148元；真实数据无报价则不补造。参考价不表示库存、交易SKU或统一全款。

## 缓存边界
公共 apiGet 缓存成功响应，包括空结果；相同请求并发合并，账号/服务器切换及成功写入清除公共缓存。
- 品牌目录、单品牌详情、店铺商品列表、日历：5分钟。
- 其他普通GET：30秒；最多16项，每项小于200,000字符，进程退出清空。
- 首页沿用已有频道快照5分钟，不叠加请求缓存，以保留主动刷新能力。
- 榜单沿用1分钟展示缓存，主动刷新绕过公共缓存。
- 健康检查、会话、同步、AI任务查询不缓存，避免遮蔽任务进展或连接问题。
- 已有页面Store快照不是公共缓存，可能继续展示上一帧直到页面刷新；并未把所有Store重写成统一缓存。
- 商品详情缓存命中不重复发起GET；若服务端以GET计浏览量，该次缓存重访不会增加服务端浏览次数。
