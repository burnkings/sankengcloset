## 截图中额外修复

- ReleaseCard 的品牌 prop 与颜色 token 同名导致颜色对象渲染成正文，颜色 token 已使用独立别名。
- PostCard 的头像文字 prop 与头像文字样式重名导致头像显示样式文本，样式已独立命名。
- 动态时间先 parseInt(ISO 字符串) 会把 2026 年误作毫秒时间戳；现在仅纯数字走数字时间戳，其余按 ISO 解析。
- 购买详情、衣橱编辑也改为 onLoad 接收路由参数。

## 动态收藏设计（本轮只讨论）

建议将点赞定义为支持作者，将收藏定义为“以后参考的搭配灵感”，两者独立。商品收藏用于关注发售与购买决策；动态收藏用于保存配色、搭配、穿法，不应出现付款状态或尾款提醒。

当前先保留点赞即可，不为凑功能加入收藏按钮。现有收藏页的动态区域实际来源于点赞，后续应先改到“我的动态 → 点赞”，避免把两种行为混称。等搭配内容足够丰富再开放独立书签收藏，在收藏页增加“搭配灵感”分区，支持去重和失效内容说明；不自动把历史点赞转成收藏。

## 后续优化建议

1. 我的工具由三列改为两列，避免“购买记录”“消费日志”断成两行；名称和数字分别成行。
2. 图片失败使用明确的失败占位与重试，演示环境优先配置可正常显示的真实图片，不用大块纯色冒充图片加载状态。
3. 提醒的“已完成”不能混入“已过期”分组，消费日志与购买记录的“本月已付”必须共用同一时间和金额口径。
4. 缺少品牌数据时隐藏空目录区，避免出现只有标题的一整块留白。
