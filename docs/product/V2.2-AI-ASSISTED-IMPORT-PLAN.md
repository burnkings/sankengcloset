# 三坑绮橱 V2.2 AI 辅助导入计划

> 状态：开发中  
> 分支：`feature/v2.2-ai-assisted-import`  
> 依赖：V2.1 后端就绪基础分支

## 1. 目标

把“图片识款”从概念入口升级为可完整演示、可替换真实模型的导入闭环：

> 选择图片 → 创建识别任务 → 生成结构化草稿 → 用户逐字段确认 → 保存到衣橱或心愿单 → 进入同步队列

AI 只负责预填，永不绕过用户确认。

## 2. 本版范围

- 支持相册/相机选择图片。
- 支持明确标注的示例识别。
- 真实用户图片在 Mock 模式下只返回低置信度安全草稿，不编造品牌与款名。
- 输出名称、坑向、品牌、价格、颜色、尺码、证据、置信度和风险提示。
- 用户可以修改所有字段，并选择保存到衣橱或心愿单。
- 保存沿用 V2.1 Store 与同步队列。
- 记录 AI 任务、模型模式、用户修正后的确认结果和目标实体 ID。
- 增加真实后端/OCR 接口、对象存储和审计字段契约。

## 3. 不做

- 不声称 Mock 已理解真实图片内容。
- 不自动保存、不自动购买、不自动创建提醒。
- 不做人脸识别、人物身份识别或身体属性推断。
- 不将图片 base64 写入同步队列。
- 不绑定具体视觉模型供应商。

## 4. 验收

- 图片选择取消时不报错。
- 真图 Mock 与示例 Mock 的文案和置信度明确区分。
- 所有 AI 字段均可修改。
- 未确认前不写入衣橱或心愿单。
- 保存后目标 Store 和同步队列同时出现记录。
- 深色模式、微信与 Android 布局遵循 V2 组件规范。
- Hermes 完成 mp-weixin、Android Vapor 和真机选择图片门禁。
