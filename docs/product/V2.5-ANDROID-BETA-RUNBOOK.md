# V2.5 Android 公网内测运行手册

## 目标

本阶段是临时 Android App 内测：前端直接访问 `http://公网IP:8787`，验证内容 Feed、商品详情、多图、账号、同步队列和个人数据闭环。它不是生产发布配置。

## 服务端启动

在云服务器的 `backend/` 中：

```bash
cp .env.example .env
# .env 至少确认：
# HOST=0.0.0.0
# PORT=8787
# DATA_DRIVER=memory
# NODE_ENV=development
npm ci
npm run typecheck
npm test
npm run dev
```

服务器本机验证：

```bash
curl http://127.0.0.1:8787/health
curl http://127.0.0.1:8787/ready
```

云平台安全组与主机防火墙仅临时放行 TCP 8787。完成内测后关闭该端口；不要长期暴露开发会话接口。

## Android App 配置

1. 云打包或制作自定义调试基座。标准真机基座不会应用 `nativeResources/android/AndroidManifest.xml`。
2. 如果云打包使用的 Android 包名不是 `io.dcloud.sankengcloset`，同步修改原生清单根节点的 `package`。
3. 安装 beta 包，进入「我的 → 同步与连接」。
4. 选择「远程服务」，输入 `公网IP:8787`。不写协议时 App 自动补 `http://`。
5. 点击「保存并检查连接」，再到账号页使用开发体验账号登录。
6. 验证首页 Feed → 商品详情、多图轮播、收藏、提醒、购买记录、同步队列。

## 验收清单

- [ ] Android 真机可通过移动网络访问 `/health`
- [ ] Feed 来自远程 API
- [ ] 商品详情调用 `GET /api/v1/products/:id`
- [ ] 多图轮播与加载失败重试正常
- [ ] 开发账号登录后可提交同步操作
- [ ] 断网时本地队列保留，恢复后重试成功
- [ ] 本地 Mock 模式仍可使用
- [ ] 页面切换、深色模式、返回栈无明显闪烁或跳顶

## 明确边界

- 当前允许明文 HTTP 仅用于临时 Android beta。
- 生产发布前必须改为 HTTPS 域名，并删除 cleartext 配置。
- `AI_PROVIDER=safe_mock` 仅验证 AI 草稿与用户确认流程；真实模型与对象存储不在本轮伪装为已接入。
- iOS 优先级最低；HarmonyOS 保留后续适配，不在本轮声称通过。
