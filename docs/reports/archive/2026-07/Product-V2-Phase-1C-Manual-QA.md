## A. 微信小程序

在微信开发者工具或微信真机中执行：

### A1. 首页首屏
- [ ] 打开小程序，首页在 1 秒内开始渲染
- [ ] 顶部显示"三坑绮橱"品牌标题、"搜索"和"通知"文字按钮
- [ ] 频道栏横滑可见：推荐/新品/预约/降价/穿搭/JK/Lolita/汉服
- [ ] "推荐"频道默认选中（品牌粉色背景白色文字）
- [ ] 焦点专题卡显示（如果有 release_event 数据）
- [ ] 第一屏可见至少 1 行双列商品卡 + 1 行单列事件/穿搭/动态卡
- [ ] 无大面积粉色 Hero、无消费统计、无快捷入口

### A2. 首页滚动到中段
- [ ] 向下滚动约半屏
- [ ] 卡片类型交替出现（商品双列 → 事件/动态/穿搭单列）
- [ ] 商品卡 3:4 比例正确，无拉伸变形
- [ ] 穿搭卡 4:5 比例正确
- [ ] 事件卡 16:9 比例正确
- [ ] 图片占位色块按分类区分（JK 粉/Lolita 紫/Hanfu 金）
- [ ] 文字可读，无过浅灰色

### A3. 首页滚动到底并触发分页
- [ ] 继续滚动到底部
- [ ] 底部显示"加载中..."
- [ ] 加载完成后新内容追加
- [ ] 底部变为"上拉加载更多"或"已显示全部内容"
- [ ] 快速连续滚动到底不会重复加载（防重入）
- [ ] 加载到 100 条后不再继续请求

### A4. 切换"预约"频道
- [ ] 点击"预约"频道标签
- [ ] 标签变为选中状态
- [ ] 内容只显示预约/定金类型的发售事件
- [ ] 切换回"推荐"后全部内容恢复

### A5. ReleaseEvent 卡片
- [ ] 发售事件卡显示类型标签（定金/预约/尾款/发售/补货/降价/预览）
- [ ] 显示相对时间（X天后/X天前）
- [ ] 显示品牌名和价格（如果有）
- [ ] 卡片整体可点击

### A6. Product 双列卡片
- [ ] 两张商品卡并排显示，宽度均分
- [ ] 图片区 3:4 比例
- [ ] 角标（新品/预售/降价）显示在右上角
- [ ] 显示商品名称（最多 2 行）+ 品牌名 + 价格
- [ ] 划线价正确显示（原价 > 现价时）

### A7. 空状态
- [ ] 切换到"汉服"频道（如果当前 Mock 汉服数量足够多则有数据）
- [ ] 如果某频道无内容，显示"暂无内容"提示
- [ ] 提示文案引导切换频道

### A8. 图片失败状态
- [ ] Mock 阶段使用色块占位，无远程图片
- [ ] 占位色块覆盖整个图片区域，无高度塌陷
- [ ] 占位文字（标题+品牌）居中显示

## B. Android App（Vapor 模式）

需要 HBuilderX 或自定义基座运行：

### B1. Vapor 首页首屏
- [ ] App 启动后首页在 1 秒内开始渲染
- [ ] list-view 使用原生 recycle list（非 scroll-view）
- [ ] 频道栏横滑流畅
- [ ] 首屏内容与微信小程序一致

### B2. 快速连续滚动
- [ ] 快速向下滑动 5 屏以上
- [ ] 无明显掉帧（60fps 目标，不低于 30fps）
- [ ] 图片占位色块不闪烁
- [ ] 回到顶部后内容正确

### B3. 加载到 100 条
- [ ] 滚动到底触发分页，重复至 100 条
- [ ] 100 条后底部显示"已显示全部内容"
- [ ] 内存占用无明显持续增长

### B4. 频道切换
- [ ] 切换频道后内容正确过滤
- [ ] 切换过程无闪烁或白屏
- [ ] 快速连续切换 3+ 个频道不会崩溃

### B5. 返回首页后滚动位置
- [ ] 滚动到中段后切换到其他 Tab
- [ ] 切换回首页后滚动位置保持
- [ ] 内容未重新加载

### B6. 内存与掉帧观察
- [ ] 连续滚动 2 分钟后检查内存
- [ ] 无持续内存泄漏趋势
- [ ] 图片占位（色块）无额外内存开销

## D. 测试数据说明

当前使用 Mock 数据：
- 10 品牌、20 商品、7 发售事件、4 品牌动态、5 穿搭
- 每页 20 条，最多 5 页 100 条
- 图片使用类别色块占位（无远程图片）
- 稳定 ID，分页防重

Mock 阶段调试入口：
- `DEBUG_FORCE_ERROR = false` → 设为 true 可触发加载失败状态
- `DEBUG_FORCE_EMPTY = false` → 设为 true 可触发空状态
- `DEBUG_EMPTY_CHANNEL = ''` → 设为某频道名可触发该频道空状态
- 以上入口仅存在于 stores/home-feed-store.uts，不暴露在 UI
