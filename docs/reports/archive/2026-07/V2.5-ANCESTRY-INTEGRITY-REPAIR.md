精确修复 ancestry 需要产生双父 merge commit。仓库设置目前禁用 merge commits；squash/rebase 都会生成线性新提交，不能证明 V2.3 真正完成点是后续版本的祖先，所以没有用“看起来合并了”的方式伪造修复。

需要仓库管理员临时启用 **Allow merge commits**，再以 merge 方式合并 PR #7；完成后可重新关闭该选项。

## 本轮恢复的真实功能

历史与当前文件对照发现，远程 Feed 已接 Fastify，但商品详情页仍直接读取 `mock-feed-repo`。这会让远程数据 ID 在详情页丢失。V2.5 已恢复：

- 新增远程商品详情服务 `GET /api/v1/products/:id`
- 详情页支持服务端 `images[]` 多图轮播
- 远程失败、空数据与重试状态
- 本地 Mock 回退保持可用
- 公网 IP 地址规范化、校验与 localhost 真机拦截
- Android 临时 HTTP beta 网络策略
